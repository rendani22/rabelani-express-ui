Rabelani Express – Documentation

Overview

Rabelani Express is a delivery and package management dashboard. It lets warehouse staff, drivers, and administrators track packages from creation through delivery, manage driver assignments, and keep customers informed at every step.

Dashboard

The dashboard provides a high-level overview of package activity, driver availability, and recent events. Use it as a starting point to monitor the daily flow of operations.

Orders & Packages

  • Create a package – Enter the receiver's email, optional notes, PO number, and line items. A unique reference code is generated automatically.
  • Track status – Packages move through: Pending → Notified → In Transit → Ready for Collection → Delivered / Collected.
  • Update a package – Edit details before the POD (Proof of Delivery) is locked.
  • Driver pickup – Mark a package as picked up by a driver, which sends the receiver an "On the Way" email.
  • Receive at collection – Mark a package as arrived at the collection point, triggering a "Ready for Collection" notification email.
  • QR labels – Print a QR code label for any package to speed up scanning at collection points.

Drivers

  • Driver list – View all driver accounts, their current availability, and live location status.
  • Add a driver – Create a new driver account with name, email, password, phone, and vehicle type.
  • Driver status – A driver is available if their location was updated within the last 10 minutes; otherwise they appear offline. While carrying a package they show as on delivery.
  • Assigned packages – Select a driver to see all packages they currently have in transit.

Live Driver Tracking

When a driver shares their GPS coordinates, a map marker is displayed on the Drivers page. Markers are colour-coded: green = available, amber = on delivery, grey = offline.

User Management

Administrators can create and manage staff accounts (warehouse staff, admins, drivers), reset passwords, and update roles. Customer / receiver profiles are managed separately under the Customers section.

Header Notifications

The bell icon in the top-right corner shows the most recent package activity (up to 10 events). Clicking an item navigates to the Orders page where you can view full details. The list refreshes automatically each time you open the panel.
